# Base Wallet Stats

Petit outil Python pour afficher des statistiques simples d'un wallet sur Base.

## Fonctionnalités

- Vérifie le solde ETH sur Base
- Affiche l'adresse analysée
- Utilise un RPC Base public
- Projet simple pour débuter Web3 + GitHub

## Installation

```bash
git clone https://github.com/TON-PSEUDO/base-wallet-stats.git
cd base-wallet-stats
pip install -r requirements.txt
```

## Utilisation

```bash
python main.py 0xTONADRESSE
```

## Exemple

```bash
python main.py 0x3A34A55c4524EEF573ea88441cF48D0462fEE130
```
